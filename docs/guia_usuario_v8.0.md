## 📋 Introducción

**CYMATIC STUDIO v8.0 "Quantum Bloom"** es la versión profesional del motor, que introduce un **canvas interactivo en 2D**, **efectos de post-procesado (Bloom)**, **exportación de fotogramas** y **grabación de video**. Esta versión marca la transición de un motor estático a un entorno visual dinámico.

## 📤 Exportación de Medios

### Captura de Fotogramas (PNG)

1. Haz clic en el botón **"📸 Frames"**.
2. El motor capturará **30 fotogramas** en intervalos de 0.5 segundos.
3. Los fotogramas se descargarán automáticamente con nombres como `frame_0001.png`, `frame_0002.png`, etc.
4. **Usa estos fotogramas** para crear animaciones o secuencias en tus proyectos.

### Grabación de Video (WebM)

1. Haz clic en el botón **"🎬 Grabar Video"**.
2. El motor grabará **10 segundos** de video a 60 FPS.
3. El archivo se descargará como `CYMATIC_<timestamp>.webm`.
4. **El video incluye** el audio del sintetizador o micrófono si están activos.

## ❓ Solución de Problemas

| Problema | Solución |
| :--- | :--- |
| **La licencia no se activa** | Verifica que la clave tenga el formato correcto (`CYMATIC-PRO-V8-XXXXXXXX`). Asegúrate de estar conectado a Internet. |
| **El video grabado no tiene audio** | Activa el micrófono o el sintetizador antes de grabar. |
| **El canvas se ve lento** | Reduce el número de líneas en el slider "Complejidad" (si está disponible). |
| **Los fotogramas no se descargan** | Verifica que el navegador tenga permisos para descargar archivos. |
