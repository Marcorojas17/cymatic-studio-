❓ Preguntas Frecuentes

Resolvemos las dudas más comunes sobre CYMATIC STUDIO.

¿Cómo recibo mi producto después de pagar?

Recibirás un correo electrónico con el enlace de descarga directa. Para pagos manuales, el envío se realiza en un plazo máximo de 24 horas después de verificar el comprobante.

¿Qué incluye la licencia?

Acceso perpetuo a la versión adquirida, actualizaciones menores durante 1 año (PRO), 2 años (ULTRA) o vitalicias (ENTERPRISE). Las licencias PRO, ULTRA y ENTERPRISE incluyen soporte prioritario.

¿Puedo usar el software en varios dispositivos?

PRO: hasta 2 dispositivos. ULTRA: hasta 3 dispositivos. ENTERPRISE: uso ilimitado en tu organización.

¿El código está protegido contra copia?

Sí. Cada archivo incluye un sistema de verificación de licencia que bloquea el acceso sin una clave válida. Además, el código está ofuscado en las versiones de pago.

¿Qué navegadores son compatibles?

Chrome 120+ (recomendado), Edge 120+, Firefox 120+, Opera 100+. Se requiere soporte para WebGL y Web Audio API.

¿Puedo obtener un reembolso?

Sí, ofrecemos una garantía de devolución de 30 días si el producto no funciona como se describe en la documentación.

¿Qué es la "marca blanca" en la versión ENTERPRISE?

Permite reemplazar el logo, nombre, colores y diseño del producto por los tuyos propios. Ideal para agencias y marcas que deseen ofrecer el motor como propio.

¿Cómo actualizo a una versión superior?

Puedes adquirir un upgrade desde el panel de cliente o contactando a ventas. El costo del upgrade es la diferencia entre el precio de tu versión actual y la nueva.
